# Local reporting-toolkit verification

- Freeze source before independent review. If a file changes afterward, invalidate that file's review coverage and obtain a bounded supplement for the changed paths; unchanged-file hashes can preserve their earlier coverage. Do not mutate code while reviewers are still reading it.
- Design adversarial tests before premium acceptance. Cover wrong-type enum values, booleans/floats masquerading as integer schema versions, missing versus malformed evidence, zero-work empty coverage, and resolved records incorrectly counted as active workload.
- Test numeric boundaries at three layers: raw JSON parsing, internal arithmetic, and complete output serialization. Include both overflow and positive-to-zero underflow, integer division followed by percentage scaling, and averages of tiny positive ratios. A finite input or intermediate is not proof of a finite or nonzero derived result.
- Use exact independent arithmetic (for example Fraction) for decimal test oracles. An expected value computed under the same inadequate ambient Decimal context can make a correct implementation fail or a rounded implementation pass. Change an oracle only with explicit parent adjudication; never weaken frozen independent tests.
- Exercise the ordinary documented CLI command, not only Python with -B. Suppressed bytecode in the test harness can hide runtime cache writes. Test symlinked parent directories and named pipes; no-follow plus nonblocking descriptor opens allow a regular-file check without first hanging on a FIFO.
- Emit only fixed error categories derived from trusted exception metadata. Do not reflect record IDs, JSON keys, or exception-message prefixes; short sensitive values defeat length/pattern redaction heuristics.
- Validate the whole report before any output. Reject nonfinite/unrepresentable serialization cleanly rather than emitting partial JSON/Markdown, Infinity, NaN, or fabricated zero.
- Combine parent-run contract tests, owner tests, reproduced reviewer regressions, one targeted mutation per workflow, negative I/O probes, and scoped cross-family review. A worker's green suite is a claim: rerun it in the parent at the exact bytes under review. For concurrent code, run the complete suite in several fresh processes and never assert worker invocation/completion order; capture executor submission order or compare per-batch identity sets because scheduler order is nondeterministic. State that synthetic examples and source references do not prove live business outcomes.
- When structured output contains one incorrect field that is wholly derived from otherwise valid child records, preserve the raw output and allow only a deterministic, replayable normalization of that field. Sign the raw value, normalized value and rule together; reject multi-field or interpretive repairs instead of turning infrastructure into an uncounted model substitute.
- Package from an explicit allowlist, never zip the whole build workspace. Exclude credential-bearing agent homes, caches and model-calling orchestration. Verify hashes after extraction and rerun the full local harness from the extracted artifact before delivery.
- Track attempts and replan limits at the project level as well as per process. A worker turn-limit exit is not an invitation to an unbounded premium fix/review loop; salvage saved work through deterministic checks, then use the controlling bounded-replan or human-HOLD policy.
